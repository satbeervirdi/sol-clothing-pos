Real-Time Automated Google Sheets Webhook

Every time you complete a bill, it can automatically append a row in your live Google Sheet in the background!

1-Step Setup: Google Apps Script Code

Instructions: In your Google Sheet, click Extensions → Apps Script, paste this code, and click Deploy → New deployment → Web app. Then paste the URL above!

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Invoice #", "Date", "Customer Name", "Customer Phone", "Items Summary", "Subtotal", "Discount", "Tax", "Grand Total", "Payment Method", "Notes"]);
  }
  sheet.appendRow([
    data.invoice_number,
    data.date,
    data.customer_name,
    data.customer_phone,
    data.items_summary,
    data.subtotal,
    data.discount,
    data.tax,
    data.grand_total,
    data.payment_method,
    data.notes
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

How to Run & Deploy Live on Mobile

Option 1: Instant in Store (Wi-Fi)

Open Directly on iPhone / Android / iPad

Ensure your mobile phone is connected to the same Wi-Fi as your Mac. Open Safari or Chrome on your phone and visit:

http://YOUR_MAC_IP:8000
Option 2: Install as Native App (PWA)

Install Icon on Phone Home Screen

  • iPhone (Safari): Tap the Share button at the bottom → tap "Add to Home Screen".
  • Android (Chrome): Tap the Three Dots ⋮ at the top right → tap "Install App" or "Add to Home screen".
  • The SOL app icon will appear right on your phone screen and open in full-screen mode with camera scanning enabled!
Option 3: Access Anywhere Over 4G / 5G

Free 1-Command Public HTTPS Cloud Tunnel

Run this single command in your Mac terminal to get an instant, free secure HTTPS link to access your POS anywhere in the city:

npx localtunnel --port 8000

Or run cloudflared tunnel --url http://localhost:8000 for a zero-trust permanent tunnel.
